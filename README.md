# Package Updater (Ubuntu)

## 📌 Description
This project is a simple Bash-based tool to install and update essential packages:

- Java (OpenJDK 17)
- Maven
- Python3
- Nginx
- Git

## 📁 Project Structure

package-updater/
├── updater.sh
├── run.sh
└── update.log

## ▶️ How to Run

chmod +x updater.sh run.sh  
./run.sh

## 📄 Logs

All logs are saved in:
update.log

## ⚠️ Requirements

- Ubuntu system
- Sudo access

## 🎯 Purpose

This project is created to practice:
- Bash scripting
- Linux package management
- Basic DevOps automation
